Accessibility / evidence and design decisions

There is no mandatory “accessible font”.

WCAG does not prescribe a typeface or a universal minimum font size. Our 24 px pixel threshold and the division of roles are design choices to reduce reading effort, not WCAG rules. No font works equally well for everyone. Source: Section508.gov.

Keep the text adaptable

Use real HTML text, allow 200% enlargement and reflow at 320 CSS px. User-defined text spacing must not hide content or controls. The “Plain typography” option replaces pixel headings with IBM Plex Mono.

Keep contrast strong

WCAG AA requires 4.5:1 for normal text and 3:1 for qualifying large text. This system keeps at least 4.5:1 for its text pairs, including pixel headings. Ink on orange is 6.42:1.

Keep essential reading smooth

Use IBM Plex Mono for actions, navigation, long text, errors and video captions. Pixel headings remain selectable text. Review actual reading with users; automated checks cannot establish universal legibility.

Sources: contrast · resize · reflow · text spacing · real text. Read the implementation guidance.

06 / Guidelines

One set of rules.
For every creator.

One source of values for the application, slides and video. This draft sets the visual direction; the product is named Wisp and uses the approved pixel ghost logo.

What stays consistent

  1. Fonts: Geist Pixel Square 400 for short headings, IBM Plex Mono 400–700 for reading, controls and code. Pixel starts at 24 px. No synthetic bold or italic.
  2. Colors: Use semantic tokens. The default application is light; the dark variant uses warm tones.
  3. Spacing: A 4 px and 8 px rhythm. Inputs and buttons are at least 44 px high. Panel radius: 16 px; control radius: 10 px.
  4. Icons: Nucleo Pixel Essential. A 24 px grid with 2 px square strokes. Scale to 48 or 72 px. Use the free selection consistently.
  5. Motif: Three connected square modules represent accumulated experience. In the workspace, keep the content dominant.
  6. Voice: English only. Short, specific sentences: “Test failed” and “Reuse”. Describe the visible state and the next step.
