#nucleo-pixel-essential

A collection of 24px React SVG icon components from the [Nucleo Pixel library](https://nucleoapp.com/pixel-icons).

> ✨ **New:** add Nucleo icons to your React projects with our new [AI Integration](https://nucleoapp.com/ai-integration).

## Installation

```bash
npm install nucleo-pixel-essential
```

## Usage

```jsx
import { IconName } from 'nucleo-pixel-essential';

function MyComponent() {
  return <IconName />;
}
```

Browse the full list of available icons on the [Nucleo Web App](https://nucleoapp.com/app/?library=pixel).

## Customization
For detailed information on customizing icons, please refer to the [Nucleo Pixel documentation](https://nucleoapp.com/react-packages?family=pixel).
